# スキル一覧（使い方ガイド）

スキル＝「この作業はこう進める」という手順書。
**該当する依頼をすれば自動で読み込まれる**ので、普通に日本語でお願いするだけでよい。
明示的に呼びたいときは `/purchase-order` `/drawing-dxf` と入力する。

---

## 📋 purchase-order（注文書作成）

**こう言えば使われる：**
- 「見積書から注文書を作って」
- 「この図面フォルダの分を注文書に入力して」
- 「注文書と見積書が合っているか確認して」
- 「注文書の並びを見積書③→②に変えて」

**やってくれること：**

| 入力 | 出力 |
|---|---|
| 見積書PDF（スキャン画像でもOK） | 注文書Excelへ 型式・品名・数量・単価 を転記 |
| 図面PDFフォルダ | 図面のQTY欄を読み、数量を転記（対称品は「本図面品/図面対称 各N個」＋合計数） |
| 入力済みの注文書 | 見積書との照合表Excel（1件ずつ突合・色分け） |

**必ずやること（自動）：**
- 編集前に**バックアップ**
- **金額を3段階で検算**（ページ小計→表紙合計→注文書合計）
- 入力後に**全件読み戻して照合**（不一致0を確認）
- 品名から加工処理表記（`(無電解ニッケル)`など）を削除
- 型式の誤記・二重発注の疑いを**報告**

## 📐 drawing-dxf（図面DXF/PDF変換）

**こう言えば使われる：**
- 「この図面をDXFにして」
- 「NTSに支給するDXFを作って」
- 「フォルダの図面を全部PDFとDXFに変換して」
- 「DXFとPDFが合っているか照合して」

**やってくれること：**
NAS上のSolidWorks図面（.SLDDRW）を**読み取り専用**で開き、DXF／PDFへ一括変換する。
1件約4〜6秒（125件で約10分）。変換後は**中身まで検証**する。

| 出力 | 作り方 | 検証内容 |
|---|---|---|
| DXF | SolidWorksの書き出し | 件数・図形要素数（空でないか） |
| PDF | **CubePDFへ印刷**（ダイアログは出ない） | 用紙サイズ・線の本数（寸法線や枠の欠落を検出） |

さらに **DXFとPDFの照合**もできる（支給前の最終チェック）。
図番がファイル名／DXF内／PDF内で一致するか、PDFの寸法値がDXFにもあるかを突き合わせる。

**⚠️ 事前にお願いすること：**
1. **SolidWorksを手動で起動しておいてください。**
   自動起動させると初期化の途中で落ちるため、起動済みのものに接続する方式にしています。
2. **出力先のPDFをAcrobat等で開いたままにしないでください。**
   開いていると上書きできず、古いファイルが残ります。

**⚠️ PDFについて2点：**
- PDFは必ず**CubePDF経由**で作ります。SolidWorks標準のPDF書き出しは
  **寸法線・矢印・図面枠・表題欄の罫線が消える**不具合があるためです（2026-08-12確認）
- シェーディングされた3Dビューが入った図面は、PDFが画像になり1〜2MBほどになります。
  **内容は欠けていないので正常**です

---

## 共通の安全ルール

- 対象のExcelファイルは**閉じておく**（開いたままだと編集できません）
- 取引先の**見積単価は社外秘**。外部にアップせずローカルExcelでやり取りします
- NASの原本は**読み取り専用**で扱い、変更しません

## 困ったときは

- 「注文書のどのページが空いてる？」→ 構造を調べて教えます
- 「変換に失敗した」→ ログ（`%TEMP%\dxf_batch_log.txt`）に1件ずつ記録されています
