# 注文書作成（見積書・図面 → 注文書Excel）

取引先からの**見積書PDF**や、社内の**図面PDF**をもとに、注文書Excelへ転記する業務。
転記ミスは金額事故・誤品製作に直結するため、**必ず機械照合で裏を取る**。

## いつ使うか

| 依頼のことば | やること |
|---|---|
| 「見積書から注文書を作って」 | 見積書PDFを読み、型式・品名・数量・単価を転記 |
| 「この図面フォルダの分を注文書に」 | 図面PDFのQTY欄を読み、型式・品名・数量を転記（単価なし） |
| 「注文書と見積書が合っているか確認して」 | 照合表Excelを作成して1件ずつ突合 |
| 「注文書の並びを変えて」 | 入力済みデータを読み取り→再配置（合計不変を検証） |

## 対象ファイルの基本

- **注文書Excel**：`3089-2603A 検査箱詰め装置(CORE SUB)_編集用_260806A.xlsx` のような装置ごとのブック
  - 取引先ごとにタブが分かれる（NTS／ステンレス工機／ヤスヒラ／田中／Misumi など）
  - 1シートに複数ページが並ぶ（詳細は `reference/order_layout.md`）
- **見積書PDF**：スキャン画像のことが多い → **目視で読み取る**（テキスト抽出は不可な場合が多い）
- **図面PDF**：CAD出力でテキストあり → **座標解析で自動抽出できる**

## 手順

### 0. 事前確認（必須）
```bash
ls -la <対象フォルダ>            # ファイルの存在・件数
```
- 注文書Excelが**開かれていないか**確認（`~$` で始まるロックファイルの有無）。開いていたら閉じてもらう
- **必ずバックアップを取ってから編集する**

### 1. 入力先ページを決める
`scripts/inspect_order_sheet.py <注文書.xlsx> <タブ名>` を実行し、
- 各ページの注文No.（例 `3089-2603A-U5`）
- 使用済み/空きページ
- 明細行の範囲

を確認して、**空いている最初のページから**入力する。

### 2-A. 見積書PDFから読み取る場合
1. `python -c "import fitz; ..."` でテキスト抽出を試す
2. テキストが無ければ **PyMuPDFで200dpiのPNGに変換して目視で読む**
3. 読み取ったら **必ずページ小計・表紙合計と検算**して一致を確認する（合わなければ読み直す）

### 2-B. 図面PDFから読み取る場合
```bash
python scripts/parse_drawing_pdf.py <図面フォルダ>
```
- 表題欄（縦書き・ラベル列の左隣が値）から 図番／品名／材質／QTY を自動抽出
- **対称品**は QTY欄が「上記」等になり、図中に「数量：本図面品/図面対称品を各N個⇒計M個」と注記される
  - → 品名の後ろに「**本図面品/図面対称 各N個**」を付け、数量は「**計M個**」を入れる

### 3. 注文書へ入力
```bash
python scripts/fill_order_sheet.py --xlsx <注文書.xlsx> --sheet <タブ名> --json <明細データ.json> --start <ページNo> --date 2026/8/6
```
- 金額列は既存の数式（=数量×単価）が計算するので触らない
- 日付は**文字列で渡す**（datetimeだとタイムゾーンで1日ずれる）

### 4. 検証（省略禁止）
```bash
python scripts/verify_order.py --xlsx <注文書.xlsx> --sheet <タブ名> --json <明細データ.json>
```
- 入力結果を読み戻して**全件突合**（不一致0を確認）
- **総合計＝見積書の合計**であることを確認

### 5. 照合表を作る（見積書がある場合）
```bash
python scripts/make_match_table.py --xlsx <注文書.xlsx> --sheet <タブ名> --json <明細データ.json> --out <照合表.xlsx>
```
左に見積書・右に注文書を並べ、判定列（一致／要確認）を色分けした確認用Excelを作る。

## 重要ルール

### 金額・数量
- **合計は必ず検算**：ページ小計 → 表紙合計 → 注文書合計 の3段階で一致を確認
- 見積書の合計と注文書の合計が**1円でも違えば入力しない**（読み取りミスを疑う）

### 品名の書き方
- **加工処理の表記は削除する**：`(無電解ニッケル)` `(アルマイト)` `(チッカ)` `(焼入れHRC55〜60)` `※処理無し`
- **部位を表す括弧は残す**：`カメラベース(裏)` の `(裏)` など
- 対称品は「品名 本図面品/図面対称 各N個」

### 型式（図番）
- **見積書の型式は誤記があり得る**。図面フォルダの実在図番と突き合わせて確認する
  - 実例：見積書`3089-400-555A`→図面`3089-400-55A`／見積書`3089-330-28A`(上下シリンダプレート)→図面`3089-330-38A`
- 同じ図番が別部品で2回出てきたら**誤記を疑って報告する**

### 安全
- **原本は必ずバックアップ**してから編集（`$TEMP` へコピー）
- Excelが開かれている状態でCOM操作しない（ロック事故・ウィンドウ非表示化が起きる）
- 取引先の**見積単価は社外秘**。外部ホスティング（Artifact等）に出さず、ローカルExcelで受け渡す

### 二重発注チェック
複数の取引先タブに**同じ図番**が入っていないか確認する。
（実例：`3089-330-37A プレート3` がNTSの見積書と板金図面の両方に存在した）
