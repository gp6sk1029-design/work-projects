# 独自ST・制御変更の撤回：F版

担当：生産技術主任補佐PDM_261102／Codex PLC編集担当
実行日：2026-11-05

ユーザー指示：勝手に追加した制御を修正し、プログラムへの影響を抑える。
元D版を基準に再作成し、番号・接点の対応修正以外を撤回した。
E版の独自受付管理は撤回済みであり、以降はF版を対象とする。

## 撤回した変更

- RCON2の追加要求保留ST、追加開始/受付ST、20ms保持、新しいM[2]～[5]の制御を削除。
- 要求ごとの新規立上り処理を取り除き、元の要求OR・Ready・100ms確認・Up・開始自己保持に戻した。
- 完了回路を元Dの100ms保持回路へ戻した。
- 独自の通信/運転許可のAND条件、数値妥当性による開始制限を撤回。
- P_Off→P_Onへの変更、監視値更新条件の変更をD版へ戻した。元の未接続テンプレートを勝手に有効化しない。
- 箱詰めの追加有効個数ST、追加ゲート、カウント初期化を撤回。
- Box_PackCount_Validや追加外部参照を除去。全変数表をD版とバイト一致へ戻した。
- 旧36行目のMoveDone接点極性もD版に戻した。動作条件は別途指示があるまで変更しない。

## 残した限定修正

1. RCON2_5の重複要求コイルを動作ごとに分離（Box3/5/8/11/37/40行をAuto1/4/2/5/6/3）。
2. Zの受け側401行にAuto4・5、コンテナ軸441行にAuto4～6を、既存と同じ並列接点として追加。
3. シリンダーの重複要求を分離。コンテナ排出戻Auto1～3、排出行Auto1～2。
4. Output280/282/286/288行の動作・異常監視へ不足する並列接点を追加。既存の手動/停止/リセットタイマー条件を保持。
5. Box11行目の前工程参照だけをM14→M16へ修正。

箱詰めのD版との差分は、コイル要求番号5か所と前工程接点1か所の計6参照のみ。
RCON_IAIは449行に戻し、D版と異なる行は401/441の受け接点追加だけ。
新しい処理・独自の時間設定・安全条件の変更は加えていない。

## 検証と限界

- 全セクションの既存ST本文はD版と一致。追加した独自STは残っていない。
- RCONの401/441行以外はD版と行単位のバイト一致。Start・完了回路・タイマーは元Dそのまま。
- 受け側OR追加の768条件について、元の回路に要求ORだけを増やした形と経路が等価であることを確認。
- Boxは42行、RCONは449行、Outputは316行。
- メーカー同梱処理の解析・モデル変換エラー0。全1356行・1580コイル接続欠落0。
- 212エントリ中D版から変更3エントリ。他209エントリはバイト一致。
- 全てのBox自動要求に受け接点があり、同じ要求の通常コイル重複なし。
- Outputは既に1024条件で検査したE版の並列接点追加とバイト一致で保持。
- 元Dの不具合・未接続条件も、今回の限定修正以外は残る。元Dの未接続P_Offは保持しているため、本修正だけで実運転可能とはしていない。
- 全体ビルド・PLCシミュレーター・実機確認は未実施。実機での無影響を保証する検証ではなく、差分を限定した静的検査。
- PLC転送なし。
